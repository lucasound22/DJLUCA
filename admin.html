DJ LUCA MARINO — SITE ADMIN

Edit copy, gallery and Mixcloud mixes. Not linked from the public site — bookmark this page.

How this works: this site has no server or database, so there's no login and no auto-save to the live site. Edit below, then:
  1. Preview — saves a draft to this browser and opens the live site so you can check it before publishing.
  2. Download content.json — grabs the updated file. Upload it to the root of your DJLUCA GitHub repo (same folder as index.html), replacing the old one. The site picks it up automatically, no rebuild needed.
  3. Or use Publish to GitHub below to skip the manual upload, if you set up a token.

Site Copy

Mixcloud Mixes

Each mix links to mixcloud.com/House_Keeping/<slug> — the slug must match the URL Mixcloud gives that mix exactly.

Gallery — Images & Videos

Paste a URL for each item (an already-hosted image, or a direct video file link — kept as plain files, no embeds). Your current 9 photos aren't in this list yet — download links for them are in the chat so you can re-host and re-add any you want to keep.

Publish directly to GitHub (optional)

Skip the manual upload. Needs a GitHub fine-grained personal access token scoped to just this repo with Contents: read and write permission. The token is stored only in this browser (never sent anywhere but api.github.com) — don't share it, and revoke it any time from GitHub settings.
